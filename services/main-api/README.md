# main-api

The main API: accounts, movies, TMDB, reviews, watchlist, lists, social features, movie nights, live screenings, weather / maps / calendar integrations and the admin dashboard. Owns the `reelhouse` MySQL database.

MVC: `routes/api.php` → `app/Http/Controllers` → `app/Models` / `app/Services`.

Runs inside Docker, see the README at the root of the project.
